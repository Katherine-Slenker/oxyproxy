# Calculate drinking water ingested

Calculate drinking water ingested

## Usage

``` r
calculate_drinking_water_ingested(df)
```

## Arguments

- df:

  Data frame containing values from Species (TotalH2OTurnover) and
  Environment (WVinLungs) functions combined with previously calculated
  values in Inputs function (FreeH2Oinfood, dryHinflux)

## Value

Numeric vector of exogenous water ingested (moles H2O)
