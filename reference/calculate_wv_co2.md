# Calculate water vapor from CO2

Calculate water vapor from CO2

## Usage

``` r
calculate_wv_co2(df)
```

## Arguments

- df:

  Data frame containing values from Species (MolesO2Air) and Inputs
  (dryHinflux,dryOinflux), and calculated value(s) of Ureaproduced

## Value

Numeric vector of CO2 water vapor values (moles H2O)
